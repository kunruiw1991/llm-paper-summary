2. Mathematical Mechanics: The FFN as a Key-Value Linear Associative Memory

In modern Transformers, Feed-Forward Network (FFN) layers function as key-value associative memories where the intermediate projection weights act as storage matrices:

MLP(x) = W_proj σ(W_fc x)
Let key k = σ(W_fc x) ∈ R^{d_m}, and W = W_proj ∈ R^{d × d_m}.
Output value v = W k ∈ R^d.

ROME's Closed-Form Constrained Least-Squares Solution:
To overwrite an association (k_*, v_*) while minimizing perturbation on pretraining keys K:

ΔW = (v_* - W k_*) (C^{-1} k_*)^T / (k_*^T C^{-1} k_*)
where C = K K^T ∈ R^{d_m × d_m} is the uncentered key covariance matrix.

MEMIT's Multi-Layer Mass Distributed Formulation:
Distributes residual targets r_b = v_*^b - W_L k_*^{b, L} evenly across layers L = {l_1, ..., l_M}:

ΔW^l = R^l [ (K^l)^T (C^l)^{-1} K^l + λ I_B ]^{-1} (K^l)^T (C^l)^{-1}
