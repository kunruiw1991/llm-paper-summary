Vygotsky's Zone of Proximal Development

In childhood learning games, if a puzzle is too easy, the child feels bored; if it is too hard, they feel frustrated and abandon the game. Voyager adapts quests targeting the sweet spot (solve rate ~75%):

P(solve) = 1 / (1 + exp(-k * (Skill_child - Difficulty_quest)))

Voyager feedback policy:

  • Solve rate > 85%: Child is mastering → stretch difficulty +0.15.
  • Solve rate < 60%: Child is struggling → scaffold difficulty -0.15.

Live ZPD Simulation Results

In our XManager study (30 simulated trials):

  • Static Progression: 70.0% frustration, 16.7% sweet spot.
  • Random Selection: 73.3% frustration, 20.0% sweet spot.
  • Voyager ZPD: 13.3% frustration, 40.0% sweet spot, +0.092 skill growth.

Companion Memory Stream Retrieval Formulation

Following Park et al. (Generative Agents), the companion (Barnaby the Bear) ranks memories for contextual recall:

S(m, q) = alpha * Recency(m) + beta * Importance(m) + gamma * Relevance(m, q)
Recency(m) = decay_factor ^ (t_current - t_created)

When the child plays a rainbow-themed level, Barnaby remembers: "Alice loves the color rainbow violet!"
