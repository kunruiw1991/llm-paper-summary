SimPO & KTO: Beyond DPO Length Bias and Paired Preferences

Step-by-step interactive explorer comparing standard DPO (unnormalized log-ratio + reference model requirement), SimPO (reference-free length-normalized reward with target margin gamma), and KTO (Kahneman-Tversky prospect theory on unpaired thumbs-up/down signals with loss aversion lambda > 1).

1. SimPO: Eliminating the Reference Model & Length Bias

DPO implicit reward accumulates sequence log-probabilities, favoring long, verbose answers. Furthermore, DPO requires loading a frozen copy of π_ref into GPU VRAM. SimPO normalizes average token log-likelihood directly:

DPO Implicit Reward: r_DPO(x, y) = β * log( π_θ(y|x) / π_ref(y|x) ) ► Needs π_ref in VRAM (2× memory). Exploits sentence length |y|. SimPO Length-Normalized Reward: r_SimPO(x, y) = (β / |y|) * ∑_{t=1}^{|y|} log π_θ(y_t | x, y_

2. KTO: Prospect Theory on Unpaired Feedback

Real-world feedback is rarely pairwise (winning vs losing response to the same prompt). KTO trains on solitary thumbs-up (+1) and thumbs-down (-1) signals using Kahneman & Tversky's loss aversion:

Kahneman-Tversky Value Function v(Δ): Desirable (y ∈ Y+): v(Δ) = σ( r(x, y) - z_0 ) Undesirable (y ∈ Y-): v(Δ) = σ( -λ * (r(x, y) - z_0) ) ► Loss aversion λ = 1.50 ~ 2.00 (losses hurt ~2× more than equal gains).
