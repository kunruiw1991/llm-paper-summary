Traditional PPO RLHF (4 Large Models in VRAM)

Standard Reinforcement Learning from Human Feedback (RLHF) optimizes a policy against an explicit neural reward model using PPO. To train a 70B model, you must keep 4 separate models in GPU memory:

  • Policy Actor (π_θ): Generates rollouts, receives policy gradient updates. (Active weights + Adam states).
  • Reference Model (π_ref): Frozen base SFT checkpoint computing KL divergence penalty.
  • Reward Model (r_φ): Frozen scalar neural network predicting preference scores.
  • Value Critic (V_ψ): Parameterized state-value estimator computing generalized advantage estimates (GAE).
Memory Overhead: 100% (2.5× to 4× base weights)
Instability: Dual actor-critic learning rate co-tuning, non-stationary critic drift.

Direct Preference Optimization (2 Models Only)

DPO proves that the optimal policy under the KL-constrained RLHF objective satisfies an exact closed-form relation to the ground-truth reward function. We can analytically solve for reward in terms of policy probabilities:

r*(x, y) = β · log( π_θ(y | x) / π_ref(y | x) ) + β · log Z(x)

By substituting this formula into the Bradley-Terry pairwise preference likelihood, the partition function Z(x) cancels out completely!

  • Zero Reward Model: No separate r_φ needed.
  • Zero Value Critic: No critic network V_ψ needed.
  • 50% GPU Memory Saving: Only π_θ (trainable) and π_ref (frozen inference or LoRA base).

The Mathematical Bridge: From Constrained RL to Binary Classification

Standard RLHF seeks to maximize expected reward while penalizing divergence from the reference policy:

max_{π} E_{x~D, y~π}[ r(x, y) ] - β · D_KL( π(y|x) || π_ref(y|x) )

The closed-form analytical maximizer of this objective is the Gibbs distribution:

π*(y | x) = (1 / Z(x)) · π_ref(y | x) · exp( (1 / β) · r(x, y) )

Taking the natural logarithm of both sides and rearranging yields the latent reward expression:

r(x, y) = β · log( π*(y|x) / π_ref(y|x) ) + β · log Z(x)

When plugged into the Bradley-Terry preference probability P(y_w > y_l | x) = σ( r(x, y_w) - r(x, y_l) ):

r(x, y_w) - r(x, y_l) = β · [ log(π_θ(y_w|x) / π_ref(y_w|x)) - log(π_θ(y_l|x) / π_ref(y_l|x)) ]

Notice: The unknown partition function log Z(x) is identical for both completions and vanishes through subtraction!
