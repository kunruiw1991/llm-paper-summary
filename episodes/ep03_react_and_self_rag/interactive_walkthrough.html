Why Naive RAG Fails: Distractor Poisoning & Fixed-Budget Retrieval

THE RETRIEVAL TAX

Standard "Naive RAG" always performs retrieval at step 0 regardless of whether the query requires external grounding, and passes top-k documents directly into the prompt context.

❌ Naive Always-On RAG Vulnerabilities

  • Distractor Corruption: If an adversarial or outdated document has high lexical overlap, the model naively integrates the false premise into its generation.
  • Context Window Waste: Queries about fundamental parametric facts (e.g. O(N^2) complexity of attention) pay retrieval latency and token clutter.
  • Single-Hop Horizon: Cannot plan multi-step information gathering paths where Query B depends on the answer to Query A.

✅ Self-RAG & ReAct Solutions

  • Adaptive Gating: Model emits [Retrieve:No] to answer purely from parametric weights without touching the index.
  • Critique-Guided Filtering: Documents are evaluated via [IsRel] and generated spans via [IsSup], pruning false claims before output.
  • Interleaved Multi-Step Trajectories: ReAct alternates Thought -> Action -> Observation until the complete multi-hop dependency is resolved.

ReAct: Synergizing Reasoning and Acting in Language Models (Yao et al., 2022)

POMDP FORMULATION

ReAct models problem solving as a Partially Observable Markov Decision Process (POMDP) where the action space is augmented: A_aug = A_env ∪ L_thought.

At step t: c_t = (q, a_1, o_1, ..., a_(t-1), o_(t-1))
Policy generates either:
1. Thought t_t ∈ L_thought (Internal deduction, plan adjustment, sub-goal decomposition)
2. Action a_t ∈ A_env (e.g. Search[entity], Lookup[keyword], Finish[answer])
Environment returns Observation o_t ∈ O

Self-RAG: Learning to Retrieve, Generate, and Critique through Self-Reflection

4 CRITIQUE TOKEN FAMILIES

Self-RAG introduces special reflection tokens trained via SFT on GPT-4 critique traces and self-reflection preference tuning:

Token Family Emitted Token Values Functional Role in Pipeline
Retrieval Gating [Retrieve:Yes], [Retrieve:No], [Retrieve:Continue] Decides at every segment boundary whether external retrieval is required or parametric knowledge suffices.
Relevance Critique [IsRel:Relevant], [IsRel:Irrelevant] Evaluates whether the retrieved document contains actionable knowledge for the current prompt.
Support / Grounding [IsSup:FullySupported], [IsSup:PartiallySupported], [IsSup:NoSupport] Detects factual hallucinations by verifying if the generated span is strictly entailed by the document.
Utility Score [IsUse:1], [IsUse:2], [IsUse:3], [IsUse:4], [IsUse:5] Quantifies the overall informativeness and clarity of the generated answer segment.

Segment-Level Beam Search & Critique Scoring Formulation

EQUATION (4) & BEAM DECODING

During inference, candidate segment beams are scored using soft token probability rewards:

Score(y_t, d) = P_LM(y_t | x, d) + γ_rel * P([IsRel:Relevant]) + γ_sup * P([IsSup:FullySupported]) + γ_use * P([IsUse:5])
If [IsSup:NoSupport] > threshold → Beam is heavily penalized or pruned to eliminate hallucinations!

Graded Self-Check Quiz (First-Principles Verification)

MASTERY CHECK

Q1: Why does Naive Always-On RAG produce hallucinations even when retrieval accuracy is high?

Correct! Without explicit critique tokens like [IsRel] and [IsSup], the generator cannot discern between authoritative facts and irrelevant or poisoning passages.

Q2: In ReAct, what is the key difference between a "Thought" and an "Action"?

Correct! ReAct augments the action space A_aug = A_env ∪ L_thought, allowing dynamic reasoning steps to precede tool interactions.

Q3: What role does the [Retrieve:No] token play in Self-RAG?

Correct! Adaptive retrieval gating allows Self-RAG to save up to 43% in context tokens on standard parametric queries.
